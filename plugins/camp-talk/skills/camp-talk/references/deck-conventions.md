# 사용자 학회 덱 구성 관례 — 과거 구두 덱 12건(2015–2026) 실측

`conf-talk-workspace/research/past_decks_survey.md`에서 추출. 새 덱은 이 골격을 기본으로 하고, 사용자가 다른 말을 하면 그 말을 따른다.

## 골격 (고정 순서)

1. **표지** — 상단 띠에 학회명·일자·세션, 중앙 제목(원고 제목 그대로), 하단 발표자·소속. 공동저자는 표지에 쓰지 않고 감사 슬라이드에.
2. **목차** — 로마숫자 Ⅰ~Ⅴ 4–5절. **절이 바뀔 때마다 목차를 재삽입하고 현재 절만 진하게** (전 덱 공통).
3. **발표자·연구실 소개 1장** — 국내 학회에서만. 국제 심포지엄·초청은 생략.
4. **Ⅰ Introduction** — 산업·시장 → 요구 성능 → 로드맵/공정 → 왜 이 문제인가 (3–5장). 산업 맥락에서 출발.
5. **Ⅱ 문제 정의·개념** — 메커니즘·이슈·제안 개념 도식 2–4장. 자기 논문의 "연구 전략 지도" 1장.
6. **Ⅲ~ 결과 블록** — 논문 단위(5–9장/편). 논문 figure 순서를 따르되 **한 슬라이드 = 한 exhibit**. 블록 상단 띠에 출처(Sun et al., 저널, 연도).
7. **결론** — 텍스트 전용 1장. (1)(2)(3) 번호 요약 + Future work 한 줄.
8. **감사** — "감사합니다 · Q&A" / "Thank you for your attention". 표지와 같은 배경. 공동연구자·지원기관은 여기.
9. **Appendix** — 감사 뒤 3–6장. 측정법·안정성·보충 데이터. 목차에 "Appendix"로 명시.

## 분량·시간

- 25분 슬롯에 본편 37장(실질 30장) → **장당 약 0.8분**. 20분이면 본편 30장(목차 재삽입 3장, 소개 1장 포함)이 사용자 습관과 일치.
- 짧은 국제 심포지엄·초청(15분)은 18–21장으로 압축하고 노트 스크립트를 길게.

## 슬라이드 단위 습관

- **제목**: 명사구·콜론 분리형("Ⅲ-2. DEM result: granule size vs peak force"). 문장형 action title은 쓰지 않는다. 대신 **슬라이드 하단에 한 줄 결론문**(KISM 2025 방식)을 둔다 → 스킬에서는 이 결론문이 academic-pptx류의 "assertion" 역할을 한다.
- 상단 띠에 절 번호·절 이름이 항상 노출.
- 그림 장당 2–5개(논문 패널 크롭 + 화살표·박스 주석), 그림 0장 슬라이드는 목차·결론·표뿐.
- 글자 장당 300–500자. 결론 슬라이드만 800–1,250자.
- **언어**: 국내 학회 = 표지·목차·서론·결론 한글 + 결과 슬라이드 제목·라벨 영어(논문 figure 그대로). 국제 학회 = 전부 영어.
- **노트**: 2024년 이후 덱은 발표 스크립트를 노트에 기록(장당 300–1,400자). 짧은 발표일수록 노트가 길다.
- 판형은 과거 4:3이 대부분이었으나 2026년부터 16:9. 새 덱은 16:9.

- 좋아한 것: Marp 시안의 깨끗한 타이포·남색 띠 인상, academic-pptx의 "한 슬라이드 한 주제, 데이터를 크게 하나씩", 영어 결과 슬라이드.
- 싫어한 것: 소제목 위치가 슬라이드마다 바뀌는 것, 세로 가운데 정렬로 위아래가 비는 것, 그림이 늘려지거나 줄여져 깨지는 것, 그림 크기를 고려하지 않은 배치, AI가 만든 듯한 획일적 카드 디자인.
