# 레이아웃 그리드와 자산(asset) 규칙 — camp-talk

이 파일은 `${CLAUDE_PLUGIN_ROOT}/skills/camp-talk/scripts/build_deck.js`가 구현하는 고정 그리드의 정본이다. 슬라이드마다 제목·띠·결론문의 위치가 절대 움직이지 않고, 그림은 원본 비율을 유지한 채 상단 정렬로 상자 안에 맞춘다. 비교테스트(iteration-1)에서 사용자가 지적한 세 결함 — 소제목 위치 변동, 세로 가운데 정렬로 비는 슬라이드, 그림 왜곡 — 을 구조로 막기 위한 것이다.

## 1. 판형과 존(zone) — 16:9, 13.333 × 7.5 in

| 존 | y 범위 (in) | x 범위 (in) | 내용 | 고정 여부 |
|---|---|---|---|---|
| band | 0.00–0.42 | 0–13.333 | 절 번호·절 이름(좌) · 슬라이드 번호(우), 남색 배경 | 항상 같은 위치 |
| title | 0.62–1.32 | 0.50–12.83 | 명사구 제목 26 pt bold, 한 줄. 70자 넘으면 22 pt | 항상 같은 y |
| content | 1.50–6.45 (높이 4.95) | 0.50–12.83 (폭 12.33) | 레이아웃별 상자 | 상단 정렬 |
| bottom line | 6.65–7.15 | 0.50–12.83 | 한 줄 결론문 14 pt bold, 연한 배경 띠 | 항상 같은 위치 |

세로 가운데 정렬은 쓰지 않는다. content 존은 위에서부터 채우고, 남는 공간은 아래쪽에만 생기게 한다. 그래야 슬라이드마다 제목과 본문 시작점이 같은 자리에 있어 청중의 시선이 흔들리지 않는다.

## 2. 레이아웃 템플릿 (content 존 안의 상자 좌표)

| layout | 그림 상자 | 텍스트/표 상자 | 불릿 | 언제 쓰나 |
|---|---|---|---|---|
| `figure-left` | x0.50 w7.40 h4.95 | x8.20 w4.63 h4.95 | 가능 | 가로형 그림(AR 1.2–2.4) 하나 + 불릿 3–5개 (기본값) |
| `figure-right` | x5.43 w7.40 h4.95 | x0.50 w4.63 h4.95 | 가능 | 위와 같으나 텍스트를 먼저 읽게 하고 싶을 때 |
| `figure-top` | x0.50 w12.33 h3.10 | x0.50 w12.33, top = 그림 하단+캡션+0.20, bottom 6.45 | 가능 | 납작한 그림(AR ≥ 2.4) — 논문 조립 패널을 가로로 잘랐을 때 |
| `figure-full` | x0.50 w12.33 h4.95 | 없음(캡션 1줄은 그림 상자 안 하단) | 불가 | 그림 자체가 메시지일 때(개념도, 3D 렌더) |
| `two-up` | 좌 x0.50 w6.00 h4.40 · 우 x6.83 w6.00 h4.40 | 각 상자 아래 캡션 h0.45 | 불가 | 정사각형에 가까운 패널 2개(AR 0.8–1.4) 대비 |
| `three-up` | w3.95 ×3 (x 0.50 / 4.69 / 8.88) h4.40 | 캡션 h0.45 | 불가 | 0/25/50% 같은 3조건 사진 |
| `figure-table` | x0.50 w6.40 h4.95 | 표 x7.20 w5.63 | 불가(표만) | 그림 + 수치 표(3–6행) |
| `figure-stack` | 상 x0.50 w7.40 h2.40 · 하 x0.50 w7.40 h2.40 | x8.20 w4.63 h4.95 | 가능 | 가로형 패널 2개를 세로로 쌓고 옆에 불릿 |
| `text-only` | 없음 | x0.50 w11.0 h4.95 (20 pt) | 가능 | 결론·조성 설명 등 |

불릿 "불가" 레이아웃에 `bullets`를 주면 빌더가 버리고 BULLET_OVERFLOW 경고만 남긴다. 말할 내용이 있으면 `figure-left`/`figure-stack`으로 바꾸거나 캡션·노트에 넣는다. `diagram`은 그림 상자 자리를 쓰며, `flow`는 상자가 세로로 길면(AR < 1.3) 단계를 세로로 쌓는다.

`layout: "auto"`이면 builder가 첫 번째 자산의 AR로 고른다: AR ≥ 2.4 → `figure-top`, 1.2 ≤ AR < 2.4 → `figure-left`, AR < 1.2 → `figure-right`(그림 상자를 h4.95에 맞추면 폭이 남아 텍스트 폭이 넓어진다). 자산 2개면 AR에 따라 `two-up` 또는 `figure-stack`, 3개면 `three-up`.

## 3. 그림 맞춤(fit) 규칙

1. **contain**: 상자 안에 원본 비율을 유지한 채 최대로 키운다. 절대 늘리거나(stretch) 자르지 않는다(crop은 자산 원장 단계에서 명시적으로만).
2. **상단·좌측 정렬**: 상자보다 작게 맞춰지면 왼쪽 위에 붙인다(`figure-full`만 가로 가운데).
3. **채움률 게이트**: 맞춘 그림 면적이 상자 면적의 55% 미만이면 builder가 경고를 낸다. 이 경고는 "레이아웃이 그림 모양과 안 맞는다"는 뜻이니 layout을 바꾸거나 그림을 크롭한다. 억지로 넓히지 않는다.
4. **해상도 게이트**: 배치 폭(in)당 원본 픽셀이 110 ppi 미만이면 경고(흐림). 원본 조립 figure에서 잘라낸 패널은 대개 800 px 안팎이라 폭 7 in 이상에 놓으면 걸린다. 이때는 `figure-stack`이나 `two-up`으로 작게 여러 개 놓거나 원본을 재플롯한다.
5. **작은 글씨 게이트**: 자산 원장의 `min_text_px`(그림 안 가장 작은 글자 높이, 원본 px)를 배치 배율로 환산해 슬라이드 상 높이가 0.12 in(≈ 9 pt) 미만이면 경고. `0`/`"none"`은 "글자 없음"이라 검사하지 않는다.
6. **두 게이트의 교집합**: 해상도 110 ppi와 글자 0.12 in을 동시에 만족하려면 원본의 가장 작은 글자가 **13.2 px 이상**이어야 한다(0.12 in × 110 ppi). 2400 px 폭 figure-set 렌더에서 잘라낸 실험 패널의 축 눈금은 보통 8–14 px라 이 조건을 못 넘긴다. 이때는 배치를 바꿔도 답이 없다. 원본을 고해상으로 다시 얻거나(figure set pptx를 600 dpi로 렌더하면 4500 px 폭, 축 눈금 글자 25 px 안팎) 원고 값으로 재플롯한다.

## 4. 텍스트 규칙

- 불릿은 최대 5개, 한 줄 14단어(한글 28자) 안팎. 16 pt(그림 옆 폭 4.63 in 기준). 넘치면 builder가 14 pt로 내리고 경고한다. 그 이상은 슬라이드를 나눈다.
- 한 슬라이드 = 한 주제 = 한 exhibit. 조립 figure 전체를 한 장에 넣지 않는다(iteration-1에서 사용자가 좋게 본 academic-pptx의 규칙).
- 결론문(bottom line)은 완전한 문장 하나. 제목은 명사구·콜론형("Ⅲ-2. DEM result: granule size vs peak force").
- 폰트: `lang: "ko"`면 제목·본문 모두 Malgun Gothic(대체 Noto Sans KR), `lang: "en"`이면 Arial. 숫자·단위는 본문과 같은 서체.

## 5. 색 토큰 (theme `navy`, Marp 시안에서 사용자가 좋아한 인상을 편집 가능 pptx로 옮긴 것)

| 토큰 | 값 | 용도 |
|---|---|---|
| band | 1F3A5F | 상단 띠 배경, 제목 밑줄 |
| ink | 1B2430 | 본문 |
| ink2 | 4B5563 | 캡션·보조 |
| accent | 0E7C7B | 강조 수치·결론문 키워드 |
| warn | B45309 | 한계·주의 카드 |
| bottom | EEF2F7 | 결론문 띠 배경 |
| paper | FFFFFF | 슬라이드 배경 |

표지·감사·구분(section) 슬라이드는 band 색 전면 배경에 흰 글씨. 그 외 슬라이드는 흰 배경.
